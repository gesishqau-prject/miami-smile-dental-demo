Miami Smile Dental V3 — AI setup

The demo works without an API key in safe mock mode.
To enable real AI for free-form questions in Windows PowerShell:

1) Open PowerShell in this folder.
2) Set your key locally (do NOT send it to anyone):
   $env:OPENAI_API_KEY="YOUR_KEY_HERE"
3) Optional model override:
   $env:OPENAI_MODEL="gpt-5.6-luna"
4) Start the server:
   node server.js
5) Open http://localhost:3000

The key stays on the server process and is never included in public/index.html.
Closing that PowerShell window clears the temporary environment variable.
