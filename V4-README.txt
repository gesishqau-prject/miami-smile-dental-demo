Miami Smile Dental V4 — Demo Dashboard

1) Run: node server.js
2) Patient chat: http://localhost:3000
3) Clinic dashboard: http://localhost:3000/dashboard.html

No API key is required. The app runs in SAFE MOCK FALLBACK mode.
Dashboard data is demo-only and kept in memory; restarting the server clears it.
Do not enter real patient information.
